Website Strategy Guide

Design, deployment, and maintenance strategy for x-peps.com — the playbook for building a world-class site, the command dictionary for working with your AI, and an honest audit of where we stand.

📊 1. Executive Summary

The Peptopia site spans two GitHub repositories and ~48 live pages, serving kratom education, peptide/GLP-1 research guides, and weekly news to drive vendor trust and orders. The transform.py standardization pipeline is our biggest win — one script enforces logos, theme toggle, print rules, and footers across every page. The biggest risks are file bloat (6.2 MB repo with 650 KB+ single files), inconsistent visual treatment across pages built at different times, and workflow fragility (the 128 KB API upload cap and binary-file corruption trap).

⚠️ Hard limits that shape our workflow

128 KB API cap: any file over ~128 KB cannot be uploaded via API — it needs David's manual drag-drop. 7 files currently exceed this.
Binary corruption: the GitHub API's create_or_update_file mangles binary files (UTF-8 encodes them). Images can ONLY go up via web UI drag-drop. Never attempt binary upload via API.
Cache: GitHub Pages caches for 10 minutes (max-age=600). Changes take up to 10 min to appear.

📅 File lifespan rules

News articles: permanent — never delete, rotate to archive dropdown after 3 weeks.
Guides: permanent — update in place, never rename (breaks links).
Archive_ files: delete after 90 days if unlinked.
Superseded batch guides (e.g. D10 → D11): keep 6 months, then archive.

🔍 6. What Works / What's Broken

✅ What works

  • transform.py pipeline — single script enforces logos, theme toggle, print rules, footers, mobile CSS across 41 pages.
  • Dual-logo theme system — dark bubble on light theme, light bubble on dark theme, file-referenced (no base64 bloat).
  • News card rotation — 3 newest cards visible, older in archive dropdown, custom SVG icon per story.
  • Print-conditional headers — guides/reports get print + toggle; index/orders get toggle only.
  • Mobile responsive chrome — header collapses cleanly at 640px.

🔑 7. Command Dictionary

Say the exact bold phrase — no extra explanation needed. Everything else is automatic.

📖 Guide Building

"Peptopia guide: [topic]"

Builds a complete Peptopia-style guide: YouTube/Reddit research, brutally honest vendor coverage, 5-effect donut cards, full graphics, standard header/footer, lowercase filename, GitHub upload.

You provide: just the topic. You get back: live URL + summary. Example: "Peptopia guide: Blue Lotus extract"

📰 News

"GLP news topics"

Researches the week's 3 freshest GLP-1/peptide/longevity stories and presents them as tappable choices. You pick one, the article is built.

Runs automatically every Monday 5 AM. Manual trigger anytime with this phrase.

🔧 Page Updates

"Standardize: [page names]"

Applies transform.py chrome to named pages: new logos, theme toggle, print rules, mobile CSS, footer. Batch as many as fit under the API limit.

You provide: page filenames. You get back: confirmation + live verification.

"Fix: [page] [issue]"

Targeted single fix. Example: "Fix: tirzepatide_guide.html missing print button"

Best for one-page, one-problem corrections.

🔬 Research

"Research: [topic]"

Deep-dive research brief WITHOUT building a page. Returns: strain/vendor profile, community consensus, negatives, pricing, donut chart percentages, sources.

Use when you want the facts first, guide later.

🖼️ Images

"Optimize images: [page]"

Audits image weight on a page, recompresses oversized PNGs, converts to efficient formats.

"New logo: [description]"

Generates a new logo variant from your description. You upload via drag-drop (binaries can't go via API).

🔍 Site Audit

"Audit site"

Full consistency check across all pages: logos, theme toggle, print buttons, footers, CSS conflicts, broken links. Returns a per-page report.

🚀 Publishing & Scheduling

"Publish: [filename]"

Uploads a local HTML file to GitHub (must be under 128 KB). Handles SHA lookup, transform, and live verification.

Multi-step pipelines (research → build → publish → announce) are chained automatically — just name the end goal.

"Schedule: [task] [when]"

Creates a recurring job. Example: "Schedule: GLP news topics every Monday 5am"

Rules

  • Hero: gradient in the page's accent color, emoticon icon, ~14px vertical padding, tag pill + H1 + one-line sub.
  • Stat cards: 4-5 per page, big number + small label, accent-colored number.
  • Visuals required per guide: hero, stat grid, effect donut card(s), at least one CSS chart or comparison table, callout boxes, section emoticons.
  • Donut chart standard: 5 families (High Energy, Mood & Well-being, Balance & Clarity, Calm & Relaxation, Relief & Warmth). Green strains: light-olive banner. White: pale gray. No number badges.
  • Typography: system sans-serif stack ONLY. Never Times New Roman or any serif.
  • Neon/glow: logo glow and button hover only. Page backgrounds stay light and airy.
  • Exemplars (match these): Imperial Green Dragon D10 guide, Foundayo news article, DTE Botanicals strain guide.
